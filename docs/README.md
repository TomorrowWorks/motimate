# Motimate 문서 안내

Motimate의 공통 문서와 기능별 기준 문서의 위치를 안내합니다.

## 문서 구분

| 경로 | 역할 |
| --- | --- |
| `PROJECT_OVERVIEW.md` | 서비스 전체 개요와 MVP 범위를 정리합니다. |
| `REPOSITORY_CONFIGURATION.md` | Repository, Branch, Issue, Pull Request 운영 규칙을 정리합니다. |
| `features/` | Backend와 Frontend가 공통으로 따라야 하는 기능 요구사항과 정책을 정리합니다. |
| `docs/backend/` | Backend 구현 참고 문서를 정리합니다. |
| `docs/frontend/` | Frontend 구현 참고 문서를 정리합니다. |

## 작성 원칙

- 제품 정책은 `features/`를 기준 문서로 작성합니다.
- Backend·Frontend 문서에는 정책을 복사하지 않고 기준 문서를 링크합니다.
- 정책·기획·설계 변경은 `discussion` 브랜치와 Draft PR 리뷰로 논의합니다.
- 리뷰가 끝나기 전에는 정책을 확정된 것으로 표시하지 않습니다.
