# motimate 프로젝트 개요

## 1. 문서 목적

이 문서는 motimate의 서비스 제공 방향, 대상 사용자, 핵심 가치와 서비스 구조를 이해관계자가 같은 기준으로 이해하도록 정리한 개요 문서입니다.

- 기준 디자인: `Figma motimate — HIFI`
- 중점 분석 범위: `💡HIFI`, `디자인시스템 / 컴포넌트`
- 보조 참고 범위: 와이어프레임의 IA 및 정책 메모
- 문서 기준일: 2026-08-30

## 2. 서비스 한 줄 정의

motimate는 사용자가 목표와 오늘의 할 일을 관리하고, 뽀모도로 타이머로 집중 세션의 시간을 기록하며, 친구와 진행 상황을 공유해 꾸준한 학습 습관을 만드는 모바일 생산성 서비스입니다.

## 3. 해결하려는 문제

학습 계획은 목표, 일정, 집중 실행, 회고가 서로 다른 도구에 흩어지기 쉽습니다. 이로 인해 다음 문제가 발생합니다.

- 장기 목표와 오늘 해야 할 행동이 연결되지 않는다.
- 계획을 세워도 실제 집중 시간과 성취 정도를 확인하기 어렵다.
- 혼자 공부할 때 동기가 쉽게 떨어지고 지속성이 낮아진다.
- 복잡한 생산성 도구는 설정 비용이 높아 사용이 오래 유지되지 않는다.
- 서비스 되고 있는 기존의 애플리케이션이 복잡하고, 필요 이상의 기능을 가지고 있어 어렵다.

## 4. 핵심 가치 제안

| 가치 | 제공 방식 |
| --- | --- |
| 명확한 방향 | 하나의 대표 목표와 D-day를 홈에서 지속적으로 노출한다. |
| 오늘의 실행 | 날짜별 할 일을 카테고리로 정리하고 완료 상태를 관리한다. |
| 집중의 가시화 | 뽀모도로 타이머로 집중 세션을 실행하고 월별·일별 집중 시간을 보여준다. |
| 사회적 동기 | 친구를 추가하고 홈에서 모티메이트 목록을 확인한다. |
| 낮은 인지 부하 | 4개 하단 탭, 단순한 화면 구조, Light/Dark 테마를 사용한다. |

## 5. 대상 사용자

### 5.1 핵심 사용자

- 시험, 자격증, 과제 등을 준비하며 계획과 집중 기록을 함께 관리하려는 학생
- 기존의 복잡한 학습 생산성 관리 도구보다 간단한 모바일 투두와 타이머를 선호하는 사용자
- 친구와 함께 공부하며 적당한 사회적 자극을 원하는 사용자

### 5.2 대표 사용 상황

1. 자격증 시험일을 대표 목표로 등록하고 D-day를 확인한다.
2. 오늘 할 일을 과목·활동별 카테고리로 등록한다.
3. 25분 집중, 5분 휴식, 3회 반복으로 집중 세션을 시작한다.
4. 완료한 할 일을 체크하고 당일 집중 시간을 확인한다.
5. 친구를 추가해 함께 학습하는 존재를 홈에서 확인한다.

## 6. 서비스 정보 구조

```text
스플래시
└─ 소셜 로그인
   └─ 홈
      ├─ 대표 목표 / D-day
      ├─ 나의 모티메이트
      ├─ 나의 집중 현황
      └─ 나의 오늘 할 일

하단 내비게이션
├─ 홈
├─ 할 일
│  ├─ 월간 달력
│  ├─ 날짜별 할 일
│  └─ 카테고리 관리
├─ 집중하기
│  ├─ 집중/휴식/횟수 설정
│  ├─ 집중 타이머
│  └─ 짧은 휴식
└─ 마이페이지
   ├─ 프로필 수정
   ├─ 다크모드
   ├─ 알림 설정
   ├─ 계정 관리
   └─ 자주하는 질문
```

## 7. 핵심 기능

### 7.1 인증과 계정

- 스플래시 화면 후 로그인 화면으로 이동
- 카카오톡 및 Apple 소셜 로그인
- 프로필 이름과 사용자 식별자(`이름#1234` 형식) 표시
- 로그인 방식 확인, 로그아웃, 회원 탈퇴

### 7.2 홈 대시보드

- 대표 목표와 D-day 표시
- 목표가 없을 때 튜토리얼 더미 표시와 빈 상태 또는 추가 진입점 제공
- 친구 목록과 관리 진입점 제공
- 월간 집중 현황과 선택 날짜의 집중 시간 제공
- 오늘의 할 일 요약 및 추가 진입점 제공

### 7.3 목표 관리

- 목표명과 목표일을 입력해 대표 목표 생성
- 달력에서 목표일 선택
- 등록된 목표 수정 및 삭제
- 목표일까지 남은 일수를 D-day로 표현

### 7.4 할 일과 카테고리

- 월간 달력에서 날짜를 선택해 할 일 조회
- 할 일 생성, 완료, 수정, 삭제
- 카테고리 생성, 색상 선택, 비공개 설정, 편집, 삭제
- 스크롤 시 달력을 축약해 할 일 목록 공간 확보

### 7.5 집중하기

- 집중 시간, 짧은 휴식 시간, 집중 횟수 설정
- 초기 제안값: 집중 25분, 휴식 5분, 3회
- 집중 세션과 짧은 휴식의 남은 시간 표시
- 화면 잠금/조작 잠금, 알림 관련 제어 제공
- 종료된 세션을 집중 통계에 반영

### 7.6 친구

- 사용자 식별자로 친구 검색 및 추가
- 내 식별자 확인
- 친구 목록 조회 및 친구 삭제
- 친구 관련 알림 설정

### 7.7 설정과 테마

- 프로필 이름 수정
- Light/Dark 모드 전환
- 친구 팔로우와 뽀모도로 관련 알림 설정
- FAQ, 로그아웃, 회원 탈퇴

## 8. 주요 사용자 여정

### 8.1 첫 사용

```text
스플래시 → 소셜 로그인 → 빈 홈
→ 대표 목표 등록 → 오늘의 할 일 등록
→ 집중 설정 → 타이머 시작 → 집중 기록 확인
```

### 8.2 일상 학습

```text
홈에서 목표와 오늘 할 일 확인
→ 할 일 탭에서 세부 계획 확인/수정
→ 집중하기에서 세션 실행
→ 할 일 완료
→ 홈에서 일별·월별 집중 현황 확인
```

### 8.3 친구 연결

```text
홈의 친구 관리 → 사용자 ID 검색
→ 결과 확인 → 친구 추가
→ 홈의 모티메이트 목록 확인 → 필요 시 삭제
```

## 10. 디자인 원칙

- Light와 Dark 테마에서 동일한 정보 구조와 기능을 제공한다.
- 핵심 행동은 Primary 계열로 강조한다.
- 기본 모서리 반경은 8px을 우선 사용한다.
- 서체는 Pretendard이며 제한된 타입 스케일을 사용한다.
- 화면은 기본·빈 상태·입력·완료·삭제 확인·비활성 상태를 구분한다.
- 삭제, 회원 탈퇴 등 되돌리기 어려운 작업은 일반 버튼과 시각적으로 구분하고, 실행 전에 사용자에게 재확인을 받는다.

## 11. MVP 범위

### 포함

- 카카오/Apple 로그인
- 프로필과 계정 관리
- 대표 목표 1개 등록·수정·삭제
- 날짜별 할 일 및 카테고리 관리
- 뽀모도로 설정·실행·기록
- 월별·일별 집중 통계
- 친구 검색·추가·삭제
- 친구의 집중 현황
- Light/Dark 모드 및 알림 설정

### 제외 또는 후속 검토

- 그룹 스터디, 채팅, 랭킹
- AI 학습 계획 추천
- 여러 대표 목표 동시 운영
- 반복 일정과 외부 캘린더 연동
- 웹/태블릿 전용 UI
- 고급 통계, 리포트 다운로드

## 13. 성공의 정의

사용자가 가입 후 짧은 시간 안에 목표와 첫 할 일을 등록하고 첫 집중 세션을 완료할 수 있어야 한다. 이후에는 홈만 보아도 오늘 해야 할 일, 목표까지 남은 기간, 친구 존재, 누적 집중 상태를 파악할 수 있어야 한다.
