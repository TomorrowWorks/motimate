# {Domain} 요구사항

상태: `Proposed`

## {DOMAIN}-REQ-{NUMBER} {요구사항 이름}

### 설명

사용자가 수행할 수 있는 기능 또는 시스템이 제공해야 하는 관찰 가능한 동작을 작성한다.

### 선행 조건

- 필요한 조건을 작성한다. 별도 조건이 없으면 `없음`으로 작성한다.

### 입력

- 필요한 논리적 입력을 작성한다. API DTO나 DB 컬럼은 작성하지 않는다.

### 정상 동작

1. 정상 사용자·시스템 흐름을 순서대로 작성한다.
2. 상세 규칙은 반복하지 않고 관련 Policy를 참조한다.

### 예외 상황

- 기능 관점에서 관찰되는 주요 예외와 기대 동작을 작성한다.

### 관련 정책

- {DOMAIN}-POL-{NUMBER}

### 완료 조건

- 충족 여부를 판단할 수 있는 관찰 가능한 조건을 작성한다.

## 제외 범위

- 사용자가 명시했거나 범위 오해를 방지하기 위해 필요한 제외 사항만 작성한다. 없으면 이 항목을 생략한다.
