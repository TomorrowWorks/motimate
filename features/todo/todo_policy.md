# 할 일 정책

상태: `Proposed`

## 할 일 입력

- 할 일 제목과 카테고리는 필수이며 메모는 선택 사항입니다.
- 할 일 제목은 앞뒤 공백을 제거한 최종 문자열을 기준으로 1~50자여야 합니다. 내부 공백은 글자 수에 포함하며 줄바꿈은 허용하지 않습니다.
- 할 일 메모는 최대 500자까지 입력할 수 있으며 줄바꿈을 허용합니다.
- 사용자는 과거·오늘·미래 날짜에 할 일을 등록할 수 있으며, 과거 날짜에 등록할 때 별도의 확인을 요구하지 않습니다.
- 같은 날짜에 제목이 동일한 할 일을 여러 개 등록할 수 있습니다.
- 날짜별 할 일 개수에는 제품상 제한을 두지 않습니다.
- 카테고리가 하나도 없으면 새 카테고리를 만들기 전까지 할 일을 등록할 수 없습니다.

## 할 일 완료와 수정

- 완료된 할 일은 완료 시각을 기록합니다.
- 과거 날짜의 할 일도 완료하거나 완료를 취소하고 수정·삭제할 수 있습니다.
- 할 일 수정 시 제목과 메모에는 생성 시와 같은 입력 조건을 적용하고 카테고리 선택을 필수로 유지합니다.
- 할 일 수정 시 다른 기존 카테고리 및 날짜는 변경할 수 없습니다.
- 날짜가 지난 미완료 할 일은 다음 날짜로 자동 이월하지 않고 원래 등록한 날짜에 유지합니다.
- 반복 할 일은 제공하지 않습니다.

## 할 일 삭제

- 개별 할 일 삭제 전에는 확인을 요구하지 않고 삭제 요청을 즉시 수행합니다.
- 삭제 후에는 짧은 실행 취소 메시지를 제공합니다.

## 정렬과 표시

- 각 카테고리 안의 할 일도 사용자가 정한 순서로 표시합니다.
- 새 할 일은 해당 목록의 마지막 순서에 배치합니다.
- 할 일 완료 상태가 변경되어도 저장된 할 일 순서는 바뀌지 않습니다.
- 할 일 드래그 재정렬은 같은 카테고리 안에서만 허용하고, 카테고리 변경은 할 일 수정 화면에서 수행합니다.
- 할 일 순서 변경은 즉시 저장합니다.
- 순서 저장에 실패하면 화면을 변경 전 순서로 복원하고 재시도를 안내합니다.
- 선택 날짜에 속한 모든 할 일을 카테고리별로 표시합니다.

카테고리의 생성, 공개 범위와 삭제가 할 일에 미치는 영향은 [카테고리 정책](../category/category_policy.md)을 따릅니다.
