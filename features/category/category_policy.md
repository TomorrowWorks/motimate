# 카테고리 정책

상태: `Proposed`

## 카테고리 생성과 편집

- 신규 계정에는 `기본 카테고리` 하나를 자동으로 생성합니다.
- 기본 카테고리는 일반 카테고리와 같은 형식으로 표시하며 이름, 색상, 공개 여부와 순서를 변경하거나 삭제할 수 있습니다.
- 카테고리 이름은 앞뒤 공백을 제거한 최종 문자열을 기준으로 1~12자여야 하며 내부 공백은 글자 수에 포함합니다.
- 동일한 계정에서는 앞뒤 공백을 제거한 카테고리 이름이 정확히 같은 경우 중복으로 처리합니다. 영문 대소문자는 서로 다른 이름으로 구분합니다.
- 카테고리 색상은 제품에서 제공하는 색상 목록 중 하나를 필수로 선택해야 하며, 여러 카테고리에 같은 색상을 사용할 수 있습니다.
- 사용자가 만들 수 있는 카테고리 개수에는 제품상 제한을 두지 않습니다.
- 모든 카테고리를 삭제할 수 있으며, 카테고리가 하나도 없으면 새 카테고리를 만들기 전까지 할 일을 등록할 수 없습니다.

## 정렬과 표시

- 새 카테고리는 카테고리 목록의 마지막 순서에 배치합니다.
- 카테고리 순서 변경은 즉시 저장합니다.
- 순서 저장에 실패하면 화면을 변경 전 순서로 복원하고 재시도를 안내합니다.

## 카테고리 공개 범위

- 새 카테고리는 기본적으로 친구에게 공개합니다.
- 사용자는 카테고리를 공개 또는 비공개로 변경할 수 있습니다.
- 비공개 카테고리는 카테고리 이름과 색상을 포함한 카테고리 자체 및 연결된 모든 할 일을 친구에게 노출하지 않습니다.

## 카테고리 삭제

- 사용 중인 카테고리를 삭제하면 해당 카테고리에 연결된 모든 할 일도 함께 삭제합니다.
- 사용 중인 카테고리를 삭제하기 전에는 함께 삭제되는 할 일이 있음을 안내하고 사용자에게 확인을 받습니다.
- 삭제가 완료되면 해당 카테고리와 연결된 할 일을 카테고리 목록, 날짜별 할 일 목록과 홈의 오늘 할 일에서 제거합니다.

할 일의 입력, 수정, 정렬과 개별 삭제 규칙은 [할 일 정책](../todo/todo_policy.md)을 따릅니다.
