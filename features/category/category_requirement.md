# 카테고리 요구사항

상태: `Proposed`

## 사용자 요구사항

### 카테고리 관리

- 카테고리 관리 화면은 기본 카테고리를 포함한 카테고리 목록, 각 항목의 드래그 핸들과 카테고리 추가 버튼을 표시해야 합니다.
- 사용자는 카테고리를 드래그해 순서를 변경할 수 있어야 하며, 변경된 순서는 즉시 저장해야 합니다.
- 카테고리 순서 저장에 실패하면 이전 순서로 복원하고 재시도 방법을 안내해야 합니다.
- 카테고리 항목을 선택하면 이름, 색상과 공개 여부를 변경하거나 카테고리를 삭제할 수 있는 편집 화면으로 이동해야 합니다.
- 카테고리 추가·편집 화면은 이름 입력, 색상 선택, 공개 여부 설정과 저장 동작을 제공해야 합니다.
- 카테고리 이름이 비어 있거나 중복되었거나 입력 조건을 충족하지 않으면 이름 입력란에 오류 원인과 수정 방법을 표시해야 합니다.
- 사용 중인 카테고리를 삭제하려 하면 연결된 모든 할 일도 함께 삭제된다는 영향을 명확히 설명하고 확인을 받아야 합니다.
- 사용 중인 카테고리 삭제가 완료되면 해당 카테고리와 연결된 할 일을 카테고리 목록, 할 일 목록과 홈에서 제거해야 합니다.
- 비공개 카테고리와 연결된 할 일은 친구 화면에 표시하지 않아야 합니다.

카테고리 변경 결과가 할 일 등록·수정·표시에 반영되는 동작은 [할 일 요구사항](../todo/todo_requirement.md)을 따릅니다.
