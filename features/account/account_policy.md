# Account 정책

상태: `Proposed`

## ACCOUNT-POL-001 로그아웃

### 정책

- 사용자는 계정 관리에서 로그아웃할 수 있다.
- 로그아웃을 실행하기 전에 사용자에게 확인을 받는다.
- 로그아웃하면 기기에 저장된 인증 정보와 개인 캐시를 삭제한다.
- 로그아웃 후에도 테마와 알림 설정은 유지된다.

### 적용 조건

- 사용자가 로그아웃을 선택할 때 적용한다.

### 예외

- 사용자가 로그아웃 확인을 취소하면 로그인 상태를 유지한다.

### 관련 요구사항

- ACCOUNT-REQ-001
- ACCOUNT-REQ-002

## ACCOUNT-POL-002 회원 탈퇴

### 정책

- 사용자는 계정 관리에서 회원 탈퇴에 진입할 수 있다.
- 회원 탈퇴를 실행하기 전에 사용자에게 확인을 받는다.
- 사용자가 탈퇴를 확인하면 즉시 서비스 이용을 중지하고 탈퇴 대상 데이터를 즉시 삭제한다.
- 탈퇴 시 목표, 할 일, 집중 기록 등의 개인 기록을 삭제한다.
- 다른 사용자의 화면에 남아 있는 관계 정보는 탈퇴 사용자로 익명화한다.
- 탈퇴 데이터 삭제가 완료된 후 동일한 소셜 계정으로 다시 가입하면 기존 계정을 복구하지 않고 신규 계정으로 처리한다.
- 탈퇴 후에도 테마와 알림 설정은 유지된다.

### 적용 조건

- 로그인된 사용자가 회원 탈퇴를 할 때 적용한다.

### 예외

- 사용자가 회원 탈퇴 확인을 취소하면 계정과 로그인 상태를 유지한다.

### 관련 요구사항

- ACCOUNT-REQ-001
- ACCOUNT-REQ-003
