# Account 요구사항

상태: `Proposed`

## ACCOUNT-REQ-001 계정 관리

### 설명

로그인된 사용자는 계정 관리에서 현재 로그인 방식과 계정 관련 기능을 확인할 수 있다.

### 선행 조건

- 사용자가 로그인된 상태이다.

### 입력

- 계정 페이지 진입

### 정상 동작

1. 시스템은 현재 로그인 방식, 로그아웃 진입점과 회원 탈퇴 진입점을 제공한다.

### 예외 상황

- 없음

### 관련 정책

- ACCOUNT-POL-001
- ACCOUNT-POL-002

### 완료 조건

- 사용자가 현재 로그인 방식을 확인할 수 있다.
- 사용자가 로그아웃 또는 회원 탈퇴 절차에 진입할 수 있다.

## ACCOUNT-REQ-002 로그아웃

### 설명

로그인된 사용자는 계정 관리에서 확인 절차를 거쳐 로그아웃할 수 있다.

### 선행 조건

- 사용자가 로그인된 상태이다.
- 사용자가 계정 관리에 진입했다.

### 입력

- 로그아웃 실행 여부

### 정상 동작

1. 사용자가 로그아웃을 선택한다.
2. 시스템은 로그아웃 실행 여부를 확인한다.
3. 사용자가 로그아웃을 확인하면 로그인 상태를 종료하고 로그인 화면으로 이동한다.

### 예외 상황

- 사용자가 확인 단계에서 로그아웃을 취소하면 로그인 상태와 계정 관리 화면을 유지한다.

### 관련 정책

- ACCOUNT-POL-001

### 완료 조건

- 확인을 클릭하지 않으면 로그아웃은 실행되지 않는다.
- 로그아웃 후 인증 정보와 개인 캐시가 기기에서 제거되고 로그인 화면이 표시된다.
- 로그아웃 후에도 후에도 테마와 알림 설정은 유지된다.

## ACCOUNT-REQ-003 회원 탈퇴

### 설명

로그인된 사용자는 계정 관리에서 확인 절차를 거쳐 회원 탈퇴할 수 있다.

### 선행 조건

- 사용자가 로그인된 상태이다.
- 사용자가 계정 관리에 진입했다.

### 입력

- 회원 탈퇴 실행 여부

### 정상 동작

1. 사용자가 회원 탈퇴에 진입한다.
2. 시스템은 회원 탈퇴 실행 여부를 확인한다.
3. 사용자가 탈퇴를 확인하면 즉시 서비스 이용을 중지하고 탈퇴 대상 데이터를 삭제한다.
4. 시스템은 다른 사용자에게 남아 있는 관계 정보를 탈퇴 사용자로 익명화한다.
5. 탈퇴 처리가 완료되면 로그인 화면으로 이동한다.

### 예외 상황

- 사용자가 확인 단계에서 회원 탈퇴를 취소하면 계정과 로그인 상태를 유지한다.

### 관련 정책

- ACCOUNT-POL-002

### 완료 조건

- 확인을 클릭하지 않으면 회원 탈퇴는 실행되지 않는다.
- 탈퇴의 확인 버튼을 클릭한 사용자는 즉시 서비스를 이용할 수 없게 된다.
- 개인 기록이 삭제되고 다른 사용자에게 남는 관계 정보가 탈퇴 사용자로 익명화된다.
- 탈퇴 완료 후 동일한 소셜 계정으로 다시 가입하면 신규 계정으로 처리된다.
- 탈퇴 후에도 테마와 알림 설정은 유지된다.
