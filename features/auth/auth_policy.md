# Auth 정책

상태: `Proposed`

## AUTH-POL-001 로그인

### 정책

- motimate는 카카오 로그인과 Apple 로그인을 제공한다.
- 로그인에 성공하면 인증이 필요한 기본 화면인 홈으로 이동한다.
- 사용자가 소셜 로그인을 취소하면 로그인 화면을 유지한다.
- 최초 소셜 로그인 사용자는 모든 필수 약관에 동의해야 계정을 생성할 수 있다.
- 사용자가 필수 약관에 동의하지 않거나 동의 절차를 취소하면 계정을 생성하지 않고 로그인 화면으로 이동한다.
- 자동 로그인 상태는 사용자가 로그아웃하거나 인증 정보가 만료 또는 폐기될 때까지 유지한다. 만료된 인증 정보는 `AUTH-POL-002`에 따라 처리한다.
- 카카오 계정과 Apple 계정은 자동으로 병합하지 않고 각각 별도 계정으로 취급한다.

### 적용 조건

- 카카오 또는 Apple 계정으로 로그인하거나 로그인 상태를 유지할 때 적용한다.

### 예외

- 없음

### 관련 요구사항

- AUTH-REQ-001
- AUTH-REQ-002
- AUTH-REQ-003

### 비고

- 필수 약관 동의 화면의 디자인이 필요하다.

## AUTH-POL-002 인증 만료

### 정책

- 인증 정보가 만료되었고 갱신할 수 있으면 사용자 개입 없이 갱신을 한 번 시도한다.
- 갱신할 수 없거나 한 번의 갱신 시도가 실패하면 로그인 화면으로 이동하고 다시 로그인하도록 안내한다.

### 적용 조건

- 로그인 상태에서 인증 정보가 만료되었을 때 적용한다.

### 예외

- 없음

### 관련 요구사항

- AUTH-REQ-003
- AUTH-REQ-004
