# Auth 요구사항

상태: `Proposed`

## AUTH-REQ-001 소셜 로그인

### 설명

사용자는 카카오 또는 Apple 계정을 이용해 motimate에 로그인할 수 있다.

### 선행 조건

- 사용자가 로그인되지 않은 상태이다.

### 입력

- 로그인에 사용할 소셜 계정

### 정상 동작

1. 사용자는 카카오 로그인 또는 Apple 로그인을 선택한다.
2. 시스템은 선택한 소셜 계정의 인증 결과를 확인한다.
3. 기존 계정의 로그인에 성공하면 홈으로 이동한다.
4. 최초 소셜 로그인이라면 필수 약관 동의 절차로 이동한다.

### 예외 상황

- 사용자가 소셜 로그인을 취소하면 로그인 화면을 유지한다.

### 관련 정책

- AUTH-POL-001

### 완료 조건

- 기존 계정으로 로그인한 사용자가 홈에 진입할 수 있다.
- 최초 소셜 로그인 사용자가 필수 약관 동의 절차에 진입할 수 있다.
- 로그인을 취소한 사용자가 로그인 화면에 머문다.

## AUTH-REQ-002 최초 계정 생성

### 설명

최초 소셜 로그인 사용자는 필수 약관에 동의한 후 motimate 계정을 생성할 수 있다.

### 선행 조건

- 사용자가 motimate 계정과 연결되지 않은 카카오 또는 Apple 계정의 인증을 완료했다.

### 입력

- 필수 약관 동의 여부

### 정상 동작

1. 시스템은 사용자에게 필수 약관 동의 절차를 제공한다.
2. 사용자가 모든 필수 약관에 동의하면 계정을 생성한다.
3. 계정 생성이 완료되면 사용자를 로그인 상태로 전환하고 홈으로 이동한다.

### 예외 상황

- 사용자가 필수 약관에 동의하지 않거나 동의 절차를 취소하면 계정을 생성하지 않고 로그인 화면으로 이동한다.

### 관련 정책

- AUTH-POL-001

### 완료 조건

- 모든 필수 약관에 동의한 사용자만 신규 계정을 생성할 수 있다.
- 미동의 또는 취소한 사용자에게 계정이 생성되지 않으며 로그인 화면이 표시된다.

## AUTH-REQ-003 로그인 상태 유지

### 설명

시스템은 유효한 인증 정보를 가진 사용자의 로그인 상태를 사용자 개입 없이 유지한다.

### 선행 조건

- 사용자가 로그인에 성공했다.

### 입력

- 유효한 인증 정보

### 정상 동작

1. 시스템은 저장된 인증 정보가 유효한 동안 로그인 상태를 유지한다.
2. 인증 정보가 만료되면 갱신 가능 여부를 확인하고 정책에 따라 처리한다.

### 예외 상황

- 사용자가 로그아웃하면 로그인 상태를 종료한다.
- 인증 정보가 폐기되거나 갱신할 수 없으면 로그인 상태를 종료하고 재로그인을 안내한다.

### 관련 정책

- AUTH-POL-001
- AUTH-POL-002

### 완료 조건

- 인증 정보가 유효한 사용자는 다시 로그인하지 않고 인증이 필요한 기능을 이용할 수 있다.
- 로그아웃하거나 유효한 인증 정보를 확보할 수 없는 사용자는 로그인 화면으로 이동한다.

## AUTH-REQ-004 인증 만료 처리

### 설명

시스템은 인증 정보가 만료되었을 때 자동 갱신을 시도하고 그 결과에 따라 로그인 상태를 처리한다.

### 선행 조건

- 로그인된 사용자의 인증 정보가 만료되었다.

### 입력

- 만료된 인증 정보

### 정상 동작

1. 시스템은 사용자 개입 없이 인증 갱신을 한 번 시도한다.
2. 갱신에 성공하면 로그인 상태와 사용 중이던 흐름을 유지한다.

### 예외 상황

- 인증 정보를 갱신할 수 없으면 로그인 화면으로 이동하고 다시 로그인하도록 안내한다.

### 관련 정책

- AUTH-POL-002

### 완료 조건

- 인증 갱신 성공 시 사용자가 로그인 상태를 유지한다.
- 갱신 불가 시 사용자가 로그인 화면과 재로그인 안내를 확인할 수 있다.

## 제외 범위

- 서로 다른 소셜 로그인 계정의 연결
