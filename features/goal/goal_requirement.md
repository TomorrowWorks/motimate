# Goal 요구사항

상태: `Proposed`

## 사용자 요구사항

- 목표명은 입력값의 앞뒤 공백을 제거한 뒤 2~20자여야 하며, 한글, 영문, 숫자, 공백만 저장할 수 있어야 합니다. 공백만 입력한 값과 줄바꿈, 특수문자, 이모지는 저장할 수 없어야 합니다.
- 사용자는 목표일을 등록하지 않고 목표를 `무기한`으로 설정할 수 있어야 합니다.
- 목표일을 등록하는 경우 오늘부터 최대 3년 이내의 날짜만 선택할 수 있어야 합니다.
- 홈 화면은 목표일에 따라 `무기한`, `D-N`, `D-Day`, `D+N`을 표시해야 합니다.
- 목표일이 지나도 목표를 자동으로 완료하거나 삭제하지 않고 `D+N`으로 표시해야 합니다.
- 목표 관리 화면에 진입하면 현재 사용자의 목표를 불러와야 합니다.
- 기존 목표가 없으면 신규 등록 상태를, 있으면 수정 상태를 제공해야 합니다.
- 목표가 없으면 생성하고, 기존 목표가 있으면 해당 목표를 수정할 수 있어야 합니다.
- 사용자는 기존 목표의 목표일을 제거해 `무기한`으로 변경할 수 있어야 합니다.
- 사용자는 삭제 확인 후 기존 목표를 삭제할 수 있어야 합니다.
- 삭제가 완료되면 목표 미등록 상태를 제공해야 합니다.
- 목표를 삭제해도 연결된 할 일과 집중 기록은 유지되어야 합니다.
- 사용자별로 동시에 하나의 목표만 저장할 수 있어야 합니다.

API endpoint와 요청·응답 형식은 [Backend Goal API 예정안](../../docs/backend/goal_api.md)에서 다룹니다.

## 제외 범위

- 다중 목표 등록
- AutoCarousel 구현
- Goal API의 백엔드 구현 및 데이터베이스 스키마 확정
- 친구의 현재 목표 조회 및 공개 권한·응답 설계
