# Goal

목표를 등록하고 목표일까지의 D-day를 표시하는 기능입니다.

## 문서

- [정책](goal_policy.md)
- [요구사항](goal_requirement.md)

## 기술 참고

- [Backend Goal API 예정안](../../docs/backend/goal_api.md)

## 상태

`Proposed`

## 범위

- 목표 입력
- 목표일 등록 또는 무기한 설정
- D-day 또는 무기한 표시
- 기존 목표 수정 연결
- 목표 삭제

다중 목표와 AutoCarousel은 현재 범위에서 제외합니다.

## 후속 범위

- 친구의 현재 목표 조회
- Friend 관계에 따른 접근 권한과 공개 응답 설계
