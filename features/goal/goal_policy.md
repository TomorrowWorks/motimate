# Goal 정책

상태: `Proposed`

## 목표 입력

- 목표명은 입력값의 앞뒤 공백을 제거한 뒤 2~20자여야 합니다. 한글, 영문, 숫자, 공백만 허용하며, 공백만 입력한 값과 줄바꿈, 특수문자, 이모지는 허용하지 않습니다.

## 목표일

- 목표일은 선택 사항이며, 등록하지 않으면 `무기한`으로 처리합니다.
- 목표일을 등록하는 경우 오늘부터 최대 3년 이내의 날짜를 선택할 수 있습니다.
- 과거 날짜는 신규 등록 또는 수정 시 선택할 수 없습니다.

## D-day 표시

| 목표일 | 표시 |
| --- | --- |
| 무기한 | `무기한` |
| 미래 | `D-N` |
| 오늘 | `D-Day` |
| 과거 | `D+N` |

- 등록된 목표일이 지나도 목표를 자동으로 완료하거나 삭제하지 않고 `D+N`으로 표시합니다.

## 등록 개수

- 동시에 등록할 수 있는 목표는 1개입니다.
- 기존 목표가 있으면 사용자에게 신규 등록 대신 기존 목표 수정 흐름을 제공합니다.
- 사용자는 목표일을 수정하거나 제거해 `무기한`으로 변경할 수 있습니다.

## 목표 삭제

- 사용자는 등록한 목표를 삭제할 수 있습니다.
- 삭제 전 사용자에게 재확인을 받습니다.
- 삭제 후에는 목표 미등록 상태로 전환합니다.
- 목표를 삭제해도 연결된 할 일과 집중 기록은 삭제하지 않고 목표와의 연결만 해제합니다.
- 삭제한 목표의 이력은 별도로 제공하지 않습니다.

## 친구 공개

- 친구 관계가 성립한 사용자에게 현재 목표를 공개합니다.
- 친구 목표의 조회 방식, 접근 권한과 응답 필드는 Friend 기능에서 정의하며 현재 Goal CRUD 범위에서는 다루지 않습니다.

## 후속 검토

- 다중 목표 등록은 후속 정책으로 검토합니다.
- 다중 목표를 지원할 때 AutoCarousel 적용 여부를 함께 검토합니다.
